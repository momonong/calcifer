使用前想知道的事

現在的 Wisp 能做到哪裡？

這版完成命令入口、安裝與診斷，介面和執行能力沿用官方 Hermes。日常、記憶、專案與工具可在同一介面使用；Wisp 自己的任務批准與候選變更合入流程仍在驗證中，尚未宣告完成。

Windows 可以直接使用嗎？

已提供 PowerShell 安裝腳本，PowerShell／CMD 與 Git Bash 共用同一份 wisp 設定，不要求 WSL。0.1.3 包含安裝探測逾時保護與 Git Bash 入口。Windows 裝置上的完整安裝、登入及重開接續仍在驗收，因此保留預覽標示。

會改掉我的 Hermes 登入嗎？

預設建立 Wisp 自己的資料目錄，不搬動原登入。首次可明確指定已有的獨立 profile；之後重裝會記住原設定，不必重新填寫，也不重建依賴。明確傳入不同設定或遇到已修改的命令時，會停止並保留現況。

需要付費嗎？

Wisp 安裝包不收費，也不附帶模型額度。實際對話與開發使用你自己供應商的登入、訂閱或 API 配額；請在 Hermes 裡確認選用的模型。

資料會送到這個網站嗎？

這裡只提供公開安裝檔與文件，沒有託管聊天或 agent。對話資料留在本機 Hermes 資料目錄；模型請求會依你選用的供應商送出。網站可能保留一般存取紀錄，沒有第三方分析程式。

如何保留現有工作、停止或移除？

Wisp 的獨立資料目錄不是作業系統沙箱，工具仍使用你的帳號權限。關閉分頁不會停止背景服務。需要停用入口時，依完整說明移除 Wisp 命令並先保留資料；不要直接刪除 Hermes home。

下載內容可以檢查嗎？

可以。安裝器會驗證固定版 ZIP 的 SHA256，封包只有入口程式與說明，不含登入或個人資料。你也可以先下載檢視，再執行。
